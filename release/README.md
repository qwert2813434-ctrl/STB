# release/

## 現行下載檔＝版本化檔名

`STB_<版本>_aarch64.dmg`（目前＝`STB_1.6.2_aarch64.dmg`）。
每次發版產生**新檔名**，不再蓋舊檔——`scripts/release-mac.sh` 會自動命名並同步
`README.md`、`docs/index.html`、工具間 `stb-latest.json` 三處連結。

**為什麼改**（2026-08-06）：舊做法是所有版本都蓋進 `STB_1.0.0_aarch64.dmg`。
① 使用者下載下來看到 1.0.0，以為抓到舊版；
② 瀏覽器不覆蓋同名檔，下載資料夾累積 `…dmg`／`…-1.dmg`／`…-2.dmg`，
**點到舊的那顆就會看到「檔案已損壞」**（7/28–8/3 那批未公證檔尤其致命）。
版本化檔名讓每顆檔案獨一無二，點錯不可能發生。

## `STB_1.0.0_aarch64.dmg`＝凍結檔，不要刪、也不要再更新

內容永久停在 **v1.6.2**。存在的唯一理由是接住指著舊網址的既有流量：
過去發出去的 IG 私訊（改不掉）、外部轉貼。

從舊連結進來的人拿到的是一顆能跑、已公證的 App，開啟後 App 內的更新橫幅
（1.5.0 起內建，讀工具間 `stb-latest.json`）會把他帶到最新版——舊連結不死，會自我修復。

> 對外新連結一律用行銷頁 <https://qwert2813434-ctrl.github.io/STB/>，
> 不要再把 DMG 直連寫進部落格／私訊／影片說明欄——那些地方改一次很貴。
> DMG 直連只出現在本 repo 內（README、docs）與 `stb-latest.json`，因為那三處腳本會自動更新。
