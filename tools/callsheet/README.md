# STB → 網頁通告單

把 STB 的案子（`project.json`）變成一份**單一 HTML 檔的三分頁通告單**：
通告單時間軸、Rundown（含分鏡縮圖）、分鏡圖。零外部連線、可離線看、可發佈成 Artifact。

**STB 案子資料夾**。裡面一定有一個 `project.json`——那就是整個案子的唯一真相，
通告、流程、地點、分鏡圖全在裡面。

## 做出來長什麼樣

一份**三分頁**的網頁：

| 分頁 | 內容 |
|---|---|
| **通告單** | 即時時鐘、集合時間、流程時間軸（拍攝當天會有走動的游標）、地圖／停車連結、聯絡人、場地照片牆 |
| **Rundown** | 每個時段一列：分鏡縮圖＋編號、地點／停車／道具、場地與停車示意圖 |
| **分鏡圖** | 全部分鏡，含景別、畫面描述、VO、SUPER |

## 三個步驟

### 1. 產生

```bash
python3 stb_to_callsheet.py <案子資料夾> 通告單.html
```

要推 Artifact 就加 `--artifact`：

```bash
python3 stb_to_callsheet.py <案子資料夾> 通告單.html --artifact
```

其他參數：

| 參數 | 用途 |
|---|---|
| `--date=2026-07-20` | 指定哪一個拍攝日（預設第一天）|
| `--maxpx=1000` | 圖片壓更小（預設長邊 1200px）|
| `--no-compress` | 不壓縮（**幾乎不要用**，見下）|

**圖片預設一定會壓縮**，長邊 1200px、JPEG q80。這不是可選項——
實測一個 16 張圖的真實案子：**5.16 MB → 0.97 MB**。腳本很容易破 40～50 張圖，
不壓的話會直接超過 Artifact 的 16MB 上限，用 LINE 傳給劇組也會慢到打不開。

分鏡卡片實際顯示寬度只有 240–300px，1200px 已經留了四倍餘裕給你在手機上捏放看細節。

> 電腦沒裝 Pillow 也能跑，腳本會自動改用 macOS 內建的 `sips`（壓縮率稍低但夠用）。

### 2. 自己開起來檢查

用瀏覽器打開產出的 HTML，對一遍下面的驗收清單。

### 3. 推上 Artifact

跟 Claude 說「**把這個檔案發佈成 Artifact**」就好。
Artifact 預設是**私有**的，要給別人看得從頁面的分享選單放出去。

## Artifact 的三個硬規則

腳本已經處理好了，但如果你要自己改版面，這三條不能違反：

**一、不能有 `<html>`／`<head>`／`<body>` 外層。**
Artifact 會自己包一層骨架，自帶會衝突。加 `--artifact` 就是在處理這件事。

**二、單頁不能超過 16MB**，內嵌圖片全部算進去。所以壓縮是必須的。

**三、不能有任何外部連線。**
Artifact 的安全政策會擋掉所有對外請求——CDN、Google Fonts、遠端圖片一律載不到。
所以 CSS/JS 全部寫在檔案裡，圖片用 `data:image` 內嵌，字型只用系統字。

> 這三條剛好也讓檔案能直接用 LINE 傳。**給劇組的話傳檔案比給網址可靠**——
> 任何人都打得開、外景現場沒訊號也看得到。

## 驗收清單

- [ ] 三個分頁都點得開
- [ ] 每個時段的起訖時間跟 STB 裡看到的一模一樣
- [ ] 最後一個時段的結束時間＝收工時間，合理
- [ ] **分鏡編號跟 STB 裡一致**（注意連續鏡是 `05-1`／`05-2`，不是 05、06）
- [ ] 地點連結點得開，會跳到 Google Maps
- [ ] 圖片有顯示（把檔案複製到桌面再開一次，確認還有圖）
- [ ] **關掉 Wi-Fi 再開一次**，版面和圖片都正常 ← 最重要
- [ ] 手機上字看得清楚、不用左右滑
- [ ] ⌘P 列印預覽是白底黑字，不會切一半

## 資料在 `project.json` 的哪裡

只需要這幾塊，其他的（調性、參考節奏、甘特圖）跟通告單無關：

```jsonc
{
  "meta":     { "title": "案名", "client": "製作公司", "taxId": "統編（可能沒有）" },
  "contacts": [ { "role": "製片", "name": "", "phone": "" } ],
  "cuts":     [ { "id":"c1", "filmId":"f1", "groupId":"g1",
                  "shot":"景別", "desc":"畫面描述", "vo":"旁白", "sup":"疊印字",
                  "imageRef":"data:image/...（分鏡圖，可能是 null）" } ],
  "refPages": { "location": [ { "title":"場景名", "note":"說明", "imageRef":"..." } ] },
  "days": [ {
    "date": "2026-07-20", "callTime": "08:00",
    "callGroups": [ { "label":"A組演員", "time":"07:30", "loc":"現場" } ],
    "rundown": [ {
      "id":"b1", "durMin":30, "type":"拍攝",
      "title":"場景A 外景日戲", "loc":"", "mapUrl":"", "park":"", "props":"", "note":"",
      "parkImage": null,           // 停車位置照
      "cutIds": ["c1","c2"]        // 這個時段要拍哪幾顆
    } ]
  } ]
}
```

### 三個一定會踩到的坑

**① `type` 有中文和英文兩種格式，都要吃。**
STB 1.6.0 之後存英文 key，之前存中文。而且轉換是「載入時在記憶體做」，
檔案要被新版存過才會寫成英文——所以實際拿到的檔案兩種都可能。

| 英文 key | 中文 | 顯示 |
|---|---|---|
| `call` / `shoot` / `move` | 集合 / 拍攝 / 移動 | 集合 / 拍攝 / 移動 |
| `setup` / `meal` / `other` | 場佈 / 用餐 / 其他 | 場佈 / 用餐 / 其他 |

認不得的值一律當「其他」，不要讓程式壞掉。

**② 時間是算出來的，不是存的。**

```
第一個時段的開始 = 這天的 callTime
每個時段的結束   = 開始 + durMin
下一個時段的開始 = 上一個時段的結束
```

所以改任何一段的長度，後面全部順延——這正是 STB 的設計。

**③ 分鏡編號不是陣列順序。**
連續鏡（相同 `groupId`）**共用主編號**並加 `-1`／`-2`；隱藏的分鏡不佔號；
多路腳本加 `A-`／`B-` 前綴。所以正確的編號可能長這樣：

```
01  02  03  04  05-1  05-2  06  07
```

用陣列索引排成 01–08 的話，現場拿通告單對分鏡會對錯。
腳本裡的 `cut_numbers()` 已經複製了 STB 的演算法。

## 版面規格（要自己改才需要看）

配色與字體是實戰修出來的，**不要自己另配一套**：

```css
--bg:#F4F4F5;   --card:#fff;      --ink:#18181B;   --ink2:#3f3f46;
--muted:#71717A; --faint:#a1a1aa; --line:#e4e4e7;  --line2:#ededf0;
font-family: -apple-system, "Helvetica Neue", "PingFang TC", "Noto Sans TC", sans-serif;
```

無彩灰階、白底黑字、無襯線。顏色只用在必要處，層次靠字級落差和留白做。

**Rundown 的縮圖尺寸比照 STB App**（這樣現場對照才不會錯亂）：

| 元件 | 規格 |
|---|---|
| 分鏡縮圖 | 96px 寬、16:9（直式案 `aspect:"9:16"` 時改 9:16）、圓角 4px |
| 縮圖編號 | 掛在縮圖正下方、11px 灰字 |
| 場地／停車示意圖 | 160px 寬、16:9、圓角 5px、左下角深色標籤 |
| 一列的版面 | 標題橫跨在上；左＝分鏡縮圖，右＝地點／停車／道具＋示意圖 |

**同一張圖出現在多個分頁時要去重**——base64 字串會整份複製，
16 張圖的案子實測會多出四成體積。腳本的 `dedupe_images()` 把圖抽成一份表，由 JS 掛回去。

## 🔴 發佈前務必看

通告單上有**工作人員姓名、電話、拍攝地點與時間**。

Artifact 預設私有，這對通告單是對的預設。但：

- **要分享前先想清楚給誰**，分享出去的連結拿到的人都看得到
- **不要放到 GitHub Pages**——那是全世界看得到、Google 也會收錄
- 給劇組最穩的還是**直接傳 HTML 檔**（LINE／Email），不需要任何網站

如果真的要一個公開網址，先把電話拿掉，或只留一組製片窗口。
